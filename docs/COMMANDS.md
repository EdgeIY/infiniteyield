# Command reference

Generated by `luajit tools/gendocs.lua` from the command registry. Do not
edit by hand.

**560 commands** in 25 categories, as of version 7.0.0.

Arguments in `<angle brackets>` are required, `[square brackets]` optional.
A command with an `off` handler also has `un<name>`, `no<name>` and
`toggle<name>`; those are listed with their parent rather than separately.

## Player selectors

Anywhere a command takes players you can use:

| Selector | Matches |
|---|---|
| `#N` | N random players |
| `%team` | players on a team |
| `ageN` | accounts newer than N days |
| `alive` | players who are alive |
| `all` | every player |
| `allies` | players on your team |
| `bacons` | players wearing default hair |
| `cursor` | the player under your cursor |
| `dead` | players who are dead |
| `enemies` | players not on your team |
| `farthest` | the furthest player |
| `friends` | your friends in the server |
| `groupN` | members of a group |
| `guests` | guest accounts |
| `me` | yourself |
| `nearest` | the closest player |
| `nonfriends` | players who are not friends |
| `nonteam` | players not on your team |
| `npcs` | humanoid NPCs in the world |
| `others` | everyone except you |
| `radN` | players within N studs |
| `random` | one random player |
| `team` | players on your team |
| `bob` | name or display name, prefix matched (an exact match wins) |
| `@bob` | account name only |
| `1234567` | user id |
| `bob,jim` | both groups |
| `all-bob` | everyone except bob |
